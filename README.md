# Тихий Лист — китайская чайная

Стартовый проект интернет-магазина китайского чая в уютной восточной эстетике с лёгким аниме-настроением.

## Что уже есть
- Адаптивная главная страница и каталог.
- Поиск, категории и сортировка.
- Карточки чая с описанием и рекомендациями по завариванию.
- Корзина и избранное с сохранением в `localStorage`.
- Чайный гид по настроению.
- Настройки бренда отдельно от компонентов.
- Демонстрационные товары, которые можно редактировать.

> Это frontend-прототип. Оформление реальных заказов, онлайн-оплата, доставка и админ-панель пока не подключены.

## Как запустить
1. Установи Node.js версии 20 или новее.
2. Открой папку проекта в VS Code.
3. Открой терминал в VS Code и выполни:

```bash
npm install
npm run dev
```

4. Перейди по локальному адресу, который покажет Vite (обычно `http://localhost:5173`).

## Как поменять название, слоган и контакты
Открой `src/config/site.ts` и измени значения.

## Как поменять цвета
Открой `src/styles/variables.css` и измени CSS-переменные в `:root`.

## Как добавить или изменить чай
Открой `src/data/products.ts`. Каждый чай — отдельный объект в массиве `products`.
- `name` — название;
- `price` — цена в рублях;
- `weight` — вес;
- `category` — категория;
- `image` — путь к изображению;
- `description` — описание;
- `flavorNotes` — вкусовые ноты;
- `brewingTemperature` и `brewingTime` — рекомендации по завариванию;
- `featured` — показывать на главной;
- `available` — доступен ли товар.

Для нового товара скопируй существующий объект, дай ему уникальные `id` и `slug`, заполни поля и сохрани файл.

## Как заменить изображение
Положи изображение в `public/images/` и укажи путь вида `/images/my-tea.jpg` в поле `image`.
Для демонстрационного прототипа часть изображений загружается с Unsplash; перед публикацией желательно заменить их на собственные фотографии и локальные файлы.

## Как собрать сайт для публикации
```bash
npm run build
npm run preview
```
Готовые файлы будут в папке `dist/`. Её можно разместить на статическом хостинге.

## Перед реальным запуском магазина
Подключи серверную часть или e-commerce платформу для заказов, остатков, персональных данных, доставки и оплаты. Не собирай реальные платёжные данные в этом frontend-прототипе.
